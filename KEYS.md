# 🔑 Ключи и доступы

## Ключ Polza AI (нужен для генерации)

1. https://polza.ai → регистрация → пополнить баланс.
2. Dashboard → API Keys → создать ключ. Современный формат — `pza_...` (старые ключи начинались с `sk-`).
3. Вставить ключ можно двумя способами:
   * **в браузере**: кнопка ключа в шапке генератора. Ключ сохраняется только у вас в localStorage и никуда, кроме `polza.ai`, не отправляется;
   * **на сервере**: `export POLZA_API_KEY=pza_...` перед запуском `generator_server.py`. Тогда ключ не видит никто из посетителей.

> ⚠️ Никогда не коммитьте рабочий ключ в репозиторий. Публичная страница = ключ утёк: любой, кто откроет исходники,
> потратит ваш баланс. Если ключ уже был в коде — перевыпустите его в панели Polza.

## Ключи фотостоков (необязательно, но дают лучшие фото)

Бесплатно, регистрация 1 минута:

| Источник | Где взять | Лимит бесплатно |
|---|---|---|
| Unsplash | https://unsplash.com/developers → New Application → Access Key | 50 запросов/час |
| Pexels | https://www.pexels.com/api/ | 200 запросов/час |
| Pixabay | https://pixabay.com/api/docs/ | 100 запросов/60 сек |

Вставить их можно в генераторе: кнопка ключа → «📷 Источники фотографий», либо на сервере через переменные окружения
`UNSPLASH_ACCESS_KEY`, `PEXELS_API_KEY`, `PIXABAY_API_KEY`.

Без ключей фото всё равно ищутся (Openverse / Wikimedia) — просто выбор беднее.
