# Примеры сайтов сгенерированных NeuraSite AI

Эти сайты были сгенерированы генератором за 30 секунд каждый на модели `anthropic/claude-sonnet-4-5` через Polza AI.

## Как сгенерить свой?

1. Открой https://kosvip369-pixel.github.io/neuralead-demo-bot/
2. Вставь Polza API ключ
3. Опиши сайт и нажми «Сгенерировать»

## Примеры

- `saas-lumen.html` — SaaS лендинг для AI-студии, темный премиум как Linear/Stripe
- `coffee-aurora.html` — Кофейня specialty, теплый уютный минимализм
- `clinic-smile.html` — Клиника эстетической медицины, светлый премиум

Открой любой HTML файл — это готовый сайт, один файл, работает без сервера.

## Промпты которые использовались

**SaaS:**
> Современный SaaS лендинг для AI-студии которая делает сайты за 30 секунд. Темный премиум дизайн как Linear, Stripe, Vercel. Hero с анимированным градиентом и мокапом, 6 фич с иконками, секция как это работает (3 шага), тарифы (3 плана), отзывы с фото, FAQ, финальный CTA. Glassmorphism, GSAP анимации

**Кофейня:**
> Лендинг для specialty кофейни, уютный теплый минимализм, много фото кофе, меню, история, адрес с картой

**Клиника:**
> Клиника эстетической медицины, светлый премиум, доверие, услуги, врачи, до/после, отзывы
