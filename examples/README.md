# Примеры сайтов

`stroy-dom.html` — пример сайта, сгенерированного более ранней версией генератора (для истории).

## Примеры, сделанные новой версией

Два живых примера (многостраничная стоматология из 3 файлов и одностраничный лендинг кофейни)
делались во время проверки генератора и показали такие результаты:

| Пример | Что проверялось | Стоимость генерации |
|---|---|---|
| многостраничник: `index.html` + `uslugi.html` + `kontakty.html` | отдельные файлы, единый дизайн, меню ссылается на файлы, ZIP | 1.91 ₽ |
| одностраничник: лендинг сети кофеен, 7 секций | реальные фото, форма брони, FAQ, анимации | 1.02 ₽ |

Файлы примеров хранились во временной папке проверки и не сохранились. Сделать такие же — 1–2 минуты:

1. Откройте https://kosvip369-pixel.github.io/Neyrogenerator/
2. Вставьте свой ключ Polza AI (окно «🔑 ключ»).
3. Опишите сайт, выберите «📑 Многостраничный сайт» и перечислите страницы через запятую
   (например: `Главная, Услуги, Контакты`), нажмите «Сгенерировать сайт».
4. Посмотрите предпросмотр, при необходимости поправьте в чате или нажмите «↻ Эту страницу».
5. Заберите результат: «⬇ Скачать» (одна страница) или «🗂 ZIP всех страниц» (весь сайт).
