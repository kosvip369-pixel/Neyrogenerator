🔑 Куда вставить ключ Polza AI?

Пошагово, за 30 секунд, чтобы генератор заработал

Шаг 1: Получи ключ (если нет)
1. Открой https://polza.ai/register
2. Регистрация 30 сек (почта+пароль)
3. Пополни 100₽ (хватит на 20 сайтов) — оплата РФ картой
4. Dashboard → API Keys → Create Key → скопируй sk-polza-...
Получить ключ →
Шаг 2: Открой генератор
Открой файл generator.html (скачай его) или по ссылке:
https://kosvip369-pixel.github.io/neuralead-demo-bot/generator.html
Если GitHub Pages не включен — просто открой generator.html двойным кликом с компьютера, он работает без сервера!
СЮДА!
Шаг 3: Вставь ключ — ВОТ СЮДА ⬇️
ПОЛЕ В ШАПКЕ САЙТА, СПРАВА ВВЕРХУ:
🔑 [_________________ sk-polza-... _________________] [👁] [OK]
В шапке генератора, справа вверху, есть поле с иконкой 🔑 и плейсхолдером "Polza API ключ (sk-polza-...)"
Вставь туда ключ и нажми OK — индикатор станет зеленым ●
Шаг 4: Генерируй!
После вставки ключа:
1. Заполни слева "Что за сайт?" (например: "Лендинг для кофейни, уютный, теплый")
2. Нажми Сгенерировать сайт
3. Через 20-40 сек появится сайт в центре
✦ Открыть генератор →
Если не открывается — скачай generator.html и открой с компьютера
Файл generator.html работает без сервера, напрямую с Polza AI
Ключ хранится только у тебя в браузере (localStorage)
