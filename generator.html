🔑 Куда вставить ключ Polza AI?

📍 Вариант 1: В браузере (для GitHub Pages) — самый простой
1. Нажми на кнопку 🔑 ключ не задан в шапке справа — откроется это окно
2. Вставь ключ Polza в поле ниже. Ключ начинается на pza_ (старые — на sk-)
3. Нажми «💾 Сохранить ключ» — ключ ляжет только в твой браузер и никуда, кроме polza.ai, не уходит
4. Кнопка в шапке станет зелёной 🔑 мой ключ — можно генерировать
Так ключ выглядит в шапке: 🔑 ключ не задан → после сохранения: 🔑 мой ключ
📍 Вариант 2: На сервере (для локального запуска / Render / Railway)
Если запускаешь python generator_server.py:
# Создай файл .env рядом с generator_server.py
cp .env.example .env
# Открой .env и вставь свой ключ:
POLZA_API_KEY=pza_твой-ключ-сюда
# необязательно — ключи фотостоков (фото точнее):
UNSPLASH_ACCESS_KEY=
PEXELS_API_KEY=
PIXABAY_API_KEY=

# Или разовой переменной без файла:
export POLZA_API_KEY=pza_...
python generator_server.py
Тогда ключ в браузере указывать не нужно: запросы идут через сервер, а в шапке появится 🛡 сервер. Файл .env уже прописан в .gitignore — в GitHub он не попадёт.
🔗 Где взять ключ Polza AI?
1. Иди на https://polza.ai/register — регистрация за 30 сек
2. Пополни баланс на 100-300₽ (хватит на 20-30 сайтов) — оплата российской картой, без VPN
3. Открой polza.ai/dashboard/api-keys → Create Key → скопируй ключ (начинается на pza_)
4. Вставь его в поле ниже и нажми «💾 Сохранить ключ»
Получить ключ на polza.ai →
🔒 Безопасность
• Ключ в браузере лежит только у тебя (localStorage этого браузера) и уходит напрямую на polza.ai — больше никуда
• Никогда не вставляй ключ в код страницы и не выкладывай его в GitHub: выложенный ключ увидят все
• Для публикации в интернете запускай generator_server.py — ключ живёт в файле .env на сервере, посетители его не видят
• Кнопка «🗑 Забыть ключ» ниже стирает ключ из этого браузера
📷 Источники фотографий (по желанию)
Без ключей фото ищутся в свободных базах (Openverse, Wikimedia) — бесплатно, но подбор грубее. Свой бесплатный ключ Unsplash / Pexels / Pixabay даёт заметно более точные фото под нишу.
