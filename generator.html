🔑 Куда вставить ключ Polza AI?

📍 Вариант 1: В браузере (для GitHub Pages) — самый простой
1. В шапке сайта найди поле 🔑 Polza API ключ (sk-polza-...) — оно вверху справа
2. Вставь туда ключ с Polza AI
3. Нажми OK — ключ сохранится в браузере (localStorage) и подсветится зеленым ●
4. Теперь можешь генерировать сайты!
📍 Вариант 2: На сервере (для локального запуска / Render / Railway)
Если запускаешь python generator_server.py:
# Создай файл .env в корне проекта
cp .env.example .env
# Открой .env и вставь:
POLZA_API_KEY=sk-polza-твой-ключ-сюда
POLZA_BASE_URL=https://polza.ai/api/v1

# Или через переменную окружения:
export POLZA_API_KEY=sk-polza-...
python generator_server.py
Тогда ключ в браузере указывать не нужно — бекенд сам проксирует запросы.
🔗 Где взять ключ Polza AI?
1. Иди на https://polza.ai/register — регистрация за 30 сек
2. Пополни баланс на 100-300₽ (хватит на 20-30 сайтов) — оплата российской картой, без VPN
3. Dashboard → API Keys → Create Key → скопируй sk-polza-...
4. Вставь в генератор!
Получить ключ на polza.ai →
🔒 Безопасность
• В браузере ключ хранится только у тебя в localStorage, никуда не отправляется кроме api.polza.ai
• Для продакшена используй бекенд (generator_server.py) — он скрывает ключ
• Можешь в любой момент удалить: очисти localStorage или нажми "Очистить" в генераторе
