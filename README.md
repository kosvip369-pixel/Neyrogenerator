# NeuraSite AI — генератор сайтов на Polza AI

Опиши сайт словами — получи готовый HTML: дизайн-система, реальные фотографии, рабочие меню, формы и анимации.
Поддерживает одностраничники и **настоящие многостраничные сайты** (отдельные файлы + ZIP).

Демо: https://kosvip369-pixel.github.io/Neyrogenerator/

## Что есть в проекте

| Файл | Назначение |
|---|---|
| `index.html` | сам генератор (весь интерфейс + логика, работает как статика на GitHub Pages) |
| `generator.html` | копия `index.html` (для старых ссылок), собирается автоматически |
| `src/` | исходники генератора: `app.core.js`, `app.gen.js`, `app.ui.js`, `runtime.js`, `build.py` |
| `generator_server.py` | серверная часть: скрывает ключ, ищет фото по своим API-ключам, отдаёт приложение |
| `examples/` | примеры сгенерированных сайтов |

Сборка: `python3 src/build.py` — собирает `index.html` и `generator.html` из `src/`.

## Как пользоваться (без сервера, GitHub Pages)

1. Откройте https://kosvip369-pixel.github.io/Neyrogenerator/
2. Вставьте свой ключ Polza AI (`pza_...`, получить: https://polza.ai → Dashboard → API Keys). Ключ хранится только в вашем браузере (`localStorage`).
3. Заполните форму: название, ниша, тип сайта, стиль, контакты, что нужно на сайте.
4. Нажмите «Сгенерировать сайт». Дальше: предпросмотр, чат для правок, «Скачать», «ZIP всех страниц».

Многостраничник: выберите «📑 Многостраничный сайт» и перечислите страницы через запятую.
Каждая страница — отдельный HTML-файл, меню в них ссылается на файлы, архив скачивается одной кнопкой.

## Как запустить с сервером (ключ не виден посетителям)

```bash
pip install -r requirements.txt
export POLZA_API_KEY=pza_ваш_ключ
uvicorn generator_server:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000 — генератор сам определит сервер (индикатор «🛡 сервер (ключ скрыт)»)
и будет ходить к Polza через него. Дополнительно:

* `UNSPLASH_ACCESS_KEY`, `PEXELS_API_KEY`, `PIXABAY_API_KEY` — фото подбираются точнее (бесплатные ключи фотобанков);
* `ALLOW_OWN_KEY=0` — запретить посетителям использовать свой ключ;
* `POST /api/publish` — публикация сайта на `/p/{slug}/`.

## Откуда берутся фотографии

1. Если заданы ключи фотостоков (Unsplash / Pexels / Pixabay) — фото берутся оттуда: точное попадание в нишу.
2. Без ключей работают свободные источники с CORS: **Openverse** (Flickr, Wikimedia, StockSnap и др.) и Wikimedia Commons — бесплатно, подбор грубее.
3. Архивные чёрно-белые снимки, сканы и схемы отсекаются фильтром, результаты сортируются по качеству и проверяются на загрузку перед вставкой в сайт.
4. Вместо выдуманных ссылок модель получает список готовых проверенных URL и обязана использовать только их.

Отдельный режим «✨ ИИ-фото» генерирует 3 фото под нишу через Polza (Seedream / Nano Banana, примерно 3-5 ₽ за фото).

## Как гарантируется, что сайт «не кривой»

* ответ модели не обрезается: при `finish_reason: length` запрос продолжается с места обрыва (до 3 раз);
* в каждую страницу вшивается рантайм: мобильное меню, показ секций при скролле, мягкий скролл по якорям, аккордеоны, рабочая форма с окном «Спасибо», кнопка «наверх», подмена битых фото;
* «страховочная сетка» снимает `opacity: 0` с элементов, если анимация появления не сработала — пустых секций не будет;
* кнопки с несуществующими функциями получают заглушку вместо мёртвого клика;
* после генерации выполняется самопроверка (кнопка «🧪 Проверить сайт»): заголовки, адаптив, дубли `id`, читаемость текста, загрузка всех фото.

## Безопасность

* В репозитории **не должно быть** рабочего ключа Polza. Если ключ попал в публичный код — считайте его скомпрометированным и перевыпустите.
* PIN владельца в `src/app.ui.js` — это не защита, а «выключатель тарифов»; не храните за ним ничего ценного.
* Сгенерированные сайты используют внешние CDN (Tailwind, Google Fonts) — для полностью автономного сайта замените их на локальные файлы.
